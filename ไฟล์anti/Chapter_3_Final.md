# บทที่ 3 วิธีการดำเนินงาน

การจัดทำโครงงานเรื่อง **ระบบวางแผนมื้ออาหารและชุมชนออนไลน์ (Ginraide)** ผู้จัดทำได้กำหนดวิธีการและขั้นตอนการดำเนินงาน ซึ่งมีรายละเอียดดังต่อไปนี้

## 3.1 ประชากรและกลุ่มตัวอย่าง
**3.1.1 ประชากร (Population)** คือ นักเรียน นักศึกษา และบุคคลทั่วไปที่ประสบปัญหาในการคิดเมนูอาหารในแต่ละวัน รวมถึงผู้ที่ต้องการประหยัดค่าใช้จ่ายในการเลือกซื้ออาหาร และผู้ดูแลระบบ (Admin)
**3.1.2 กลุ่มตัวอย่าง (Sample)** คือ คัดเลือกแบบเจาะจง (Purposive Sampling) แบ่งเป็นกลุ่มผู้ใช้งานทั่วไป จำนวน 25 คน และกลุ่มผู้ดูแลระบบ จำนวน 5 คน รวมทั้งสิ้น 30 คน

## 3.2 เครื่องมือที่ใช้ในการดำเนินงานโครงงาน
**3.2.1 เครื่องมือด้านฮาร์ดแวร์ (Hardware)**
1) คอมพิวเตอร์โน้ตบุ๊ก สำหรับการเขียนและพัฒนาระบบ
2) สมาร์ทโฟน สำหรับการทดสอบการแสดงผลหน้าจอแบบ Responsive Design
**3.2.2 เครื่องมือด้านซอฟต์แวร์และเทคโนโลยี (Software & Technology)**
1) Front-end: React.js (Vite), Tailwind CSS
2) Back-end & API: Node.js, Express.js
3) Database: Supabase (PostgreSQL), Prisma ORM
4) Deployment: Vercel
**3.2.3 Development & Documentation Tools**
1) Windows 10/11 ใช้เป็นระบบปฏิบัติการหลัก
2) Visual Studio Code ใช้เป็นโปรแกรมแก้ไขโค้ด (Code Editor)
3) Node.js (Node Portable) และ npm ใช้เป็นสภาพแวดล้อมในการจำลองเว็บเซิร์ฟเวอร์
4) GitHub และ GitHub Desktop ใช้สำหรับจัดเก็บและควบคุมเวอร์ชันของซอร์สโค้ด
5) Google Chrome ใช้ทดสอบรันหน้าเว็บและตรวจสอบการทำงานของ API
6) Microsoft Office Word ใช้จัดทำรายงาน
**3.2.4 เครื่องมือที่ใช้ในการเก็บรวบรวมข้อมูล**
แบบสอบถามความพึงพอใจของผู้ใช้งานระบบ (Questionnaire) สร้างขึ้นในรูปแบบมาตราส่วนประมาณค่า (Rating Scale) 5 ระดับ ตามวิธีของลิเคิร์ท (Likert Scale) เพื่อใช้วัดความพึงพอใจและประเมินประสิทธิภาพการทำงานของระบบวางแผนมื้ออาหารและชุมชนออนไลน์ Ginraide

## 3.3 การวิเคราะห์ระบบ
**3.3.1 กระแสข้อมูล (Data Flow Diagram)**
*(นำรูปภาพ DFD ที่แคปหน้าจอไว้มาวางตรงนี้)*
**ภาพที่ 3.X** แผนภาพกระแสข้อมูล (Data Flow Diagram) ของระบบ Ginraide แสดงการไหลของข้อมูลระหว่างผู้ใช้งานทั่วไป (User) และผู้ดูแลระบบ (Admin) กับระบบจัดการฐานข้อมูล

**3.3.2 ความสัมพันธ์ของฐานข้อมูล (Entity Relationship Diagram)**
*(นำรูปภาพ ER-Diagram จากเว็บ dbdiagram.io มาวางตรงนี้)*
**ภาพที่ 3.X** แผนภาพแสดงความสัมพันธ์ระหว่างข้อมูล (ER-Diagram) ของระบบ Ginraide 

**3.3.3 Data Dictionary**
*(นำตารางพจนานุกรมข้อมูลทั้ง 10 ตารางที่คุณก๊อปปี้ไว้ก่อนหน้านี้มาวางในหัวข้อนี้เรียงลงมาได้เลยครับ)*

**3.3.4 Site Map**
โครงสร้างแผนผังเว็บไซต์ (Sitemap) ของระบบ Ginraide ถูกแบ่งออกเป็น 2 ส่วนหลักตามสิทธิ์การใช้งาน ได้แก่
1) **ส่วนของผู้ใช้งานทั่วไป (User):** หน้าหลัก (หน้าโซเชียล), ค้นหาเมนูคอมโบเซเว่น, ค้นหาเมนูจากตู้เย็น, และหน้าจัดการโปรไฟล์
2) **ส่วนของผู้ดูแลระบบ (Admin Dashboard):** หน้าจัดการตารางเมนูคอมโบ, ข้อมูลสินค้าเซเว่น, เมนูตู้เย็น, วัตถุดิบ และสถิติรวมของระบบ

## 3.4 ออกแบบหน้าจอโปรแกรม
การออกแบบส่วนติดต่อผู้ใช้งาน (UI/UX) มุ่งเน้นการใช้งานผ่านโทรศัพท์มือถือเป็นหลัก (Mobile-first Design) โดยใช้ Tailwind CSS ในการจัดโครงสร้าง เลย์เอาต์การแสดงผลการค้นหาเมนูออกแบบให้เป็นแบบ 2 คอลัมน์ (Grid) เพื่อให้แสดงผลเมนูได้ชัดเจนและไม่แออัด ส่วนหน้าโซเชียลออกแบบให้คล้ายคลึงกับแพลตฟอร์มที่ผู้ใช้คุ้นเคย (Facebook-style) เพื่อให้ง่ายต่อการใช้งาน

## 3.5 การทดสอบระบบ
1) **Unit Testing:** ทดสอบการทำงานของฟังก์ชันย่อย เช่น ระบบการกดไลก์ต้องไม่คำนวณจนยอดไลก์ติดลบ
2) **Integration Testing:** ทดสอบการทำงานร่วมกันระหว่างหน้าบ้าน (Frontend) และหลังบ้าน (Backend) เช่น เมื่อ Token เข้าสู่ระบบหมดอายุ ระบบจะดักจับ (Catch 401) และแจ้งเตือนให้ผู้ใช้เข้าสู่ระบบใหม่
3) **User Acceptance Testing (UAT):** นำระบบให้กลุ่มเป้าหมายทดลองใช้งานจริง เพื่อหาจุดบกพร่องและแก้ไขเลย์เอาต์ที่แสดงผลทับซ้อนกันก่อนนำขึ้นใช้งานจริงบน Vercel

## 3.6 ศึกษาวิเคราะห์และการเก็บรวบรวมข้อมูล
1) นำระบบ Ginraide ไปให้ผู้เชี่ยวชาญและกลุ่มตัวอย่างได้ทดลองใช้งานผ่านอุปกรณ์จริง
2) ให้ผู้ใช้งานประเมินความพึงพอใจผ่านแบบสอบถามออนไลน์ (Google Forms)
3) รวบรวมข้อมูลและข้อเสนอแนะที่ได้ นำมาสรุปผลเพื่อปรับปรุงระบบให้สมบูรณ์ยิ่งขึ้น

## 3.7 ศึกษาวิเคราะห์ข้อมูลและสถิติที่ใช้
วิเคราะห์ข้อมูลแบบสอบถามความพึงพอใจ โดยใช้สถิติพื้นฐาน ได้แก่
1) ค่าเฉลี่ย (Mean)
2) ส่วนเบี่ยงเบนมาตรฐาน (Standard Deviation: S.D.)

**เกณฑ์การแปลผลคะแนนเฉลี่ย 5 ระดับ (Likert Scale):**
- 4.50 - 5.00 หมายถึง มีความพึงพอใจระดับ มากที่สุด
- 3.50 - 4.49 หมายถึง มีความพึงพอใจระดับ มาก
- 2.50 - 3.49 หมายถึง มีความพึงพอใจระดับ ปานกลาง
- 1.50 - 2.49 หมายถึง มีความพึงพอใจระดับ น้อย
- 1.00 - 1.49 หมายถึง มีความพึงพอใจระดับ น้อยที่สุด
